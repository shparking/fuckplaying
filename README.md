# 주루윷놀이 (Juruyut)

팀을 나눠 각자 폰으로 윷을 던지는 술자리 윷놀이 웹앱이에요. 같은 방에 들어온 모든 폰이 Firebase Realtime Database 로 실시간 동기화되고, 윷판의 모든 칸에 미션·미니게임·놉카드가 들어 있어요. 주루마블과 같은 Firebase 프로젝트를 쓰지만 데이터 위치(`yutRooms`)가 달라서 서로 섞이지 않아요.

## 1. Firebase 준비

주루마블에서 만든 `juru-marvel` 프로젝트를 그대로 써요. 콘솔 → Realtime Database → 규칙 탭에 아래 내용을 붙여넣고 **게시**하세요 (`database.rules.json` 과 같음). 주루마블(`rooms`)과 주루윷놀이(`yutRooms`)를 둘 다 열어 두는 규칙이고, 테스트 모드와 달리 만료가 없어요.

```json
{
  "rules": {
    "rooms": { ".read": true, ".write": true },
    "yutRooms": { ".read": true, ".write": true }
  }
}
```

다른 Firebase 프로젝트를 쓰려면 `src/firebase.js` 의 설정값을 바꾸고, 미국 리전이 아니면 `.env` 에 `VITE_FIREBASE_DB_URL` 을 넣으세요 (`.env.example` 참고).

## 2. 배포 (GitHub → Vercel)

이 저장소를 Vercel 에서 Import 하면 끝이에요. Framework 는 Vite 로 자동 인식되고, Build Command `npm run build`, Output `dist` 가 기본값이에요. main 브랜치에 push 할 때마다 자동으로 다시 배포돼요.

**🎵 노래 맞히기**는 Vercel 서버 함수 `api/media.js` 가 미리듣기를 찾아요: 목록 곡은 `/api/media?i=번호` (Deezer → 없으면 Apple, 키 필요 없음), 지금 차트는 `/api/media?chart=1` (Apple Music 한국 '많이 듣는 곡' Top 100 + iTunes 미리듣기, 30분 캐시). **🎬 이모지 영화 맞히기**는 찾을 게 없어요 (TMDB 키도 필요 없음). 배포한 뒤 `/?mediacheck=1` 에서 목록 노래마다 미리듣기를 찾는지, 지금 차트가 오는지 한 번에 확인할 수 있어요 (맨 위에 서버 함수 상태 — `/api/media?ping=1`, 못 찾은 것만 복사 버튼).

## 3. 실행 (내 컴퓨터)

```bash
npm install
npm run dev
```

`http://localhost:5173/?demo=1` 로 열면 서버 없이 한 기기에서 가짜 참가자 3명과 함께 미리 볼 수 있어요. (`npm run dev` 에는 서버 함수 `api/` 가 없어서 노래 맞히기는 노래를 못 불러와요 — 배포된 사이트나 `vercel dev` 에서 확인, 이모지 영화 맞히기는 그냥 돼요)

## 4. 화면

주루마블과 다른 **포장마차 네온** 테마예요. 기본은 밤(남색 밤하늘 + 네온 주황·소주병 초록·핑크), 오른쪽 위 해 버튼을 누르면 낮(주황 천막·크림)으로 바뀌어요. 제목·버튼 글씨는 간판 느낌의 Black Han Sans(`@fontsource/black-han-sans`, 앱에 같이 묶여서 배포), 본문은 Pretendard 예요.

게임 화면은 위에 팀 점수판(팀별 말 ○집 ●판 ◎골인과 골인 수), 가운데 윷판, 그 아래 팀원·놉카드 목록이 있고, 화면 아래에 고정된 조작 바에서 지금 차례·윷 결과·말 고르기·던지기를 해요. 윷가락이 돌아가는 동안에는 결과 칩과 윷가락 모양을 숨겨서 미리 보이지 않아요.

윷판은 **10×10** (한 변에 10칸, 바깥 36칸 + 대각선 16칸 + 가운데 = 53칸)이에요. 판은 항상 한 화면에 전체가 보이고, 칸마다 번호·이모지·벌칙 글자가 같이 보여요 (크게/작게 보기 전환 없음). 모서리(9·18·27번)와 가운데(40번)는 **보라 네온 테두리**예요 (주황 깜빡임은 '갈 수 있는 칸' 전용이라 헷갈리지 않게). 칸을 거의 맞닿게 키우고 판을 화면 가장자리까지 넓혔고, 글자는 **모든 칸이 같은 크기**(판 너비의 1.9%, `YutBoard.jsx` 의 `CELL_FS`)이고, 그 크기로 안 들어가는 줄만 띄어쓰기에서 나누며, 나눠도 안 들어가는 긴 단어만 그 칸에서 조금 작아져요 (`fitCellText`). 글자 크기는 판 너비 기준(CSS 컨테이너 단위 cqw)이라 어느 화면에서든 같은 모양이에요. 칸 글자는 한 줄 4자 안팎, 세 줄 이내면 다른 칸과 같은 크기로 보여요. 말은 칸 오른쪽 위 모서리에 서 있는 **작은 수달**(팀 색 목띠·받침, 아래 8번)이고 그 칸 테두리가 팀 색으로 빛나요. 업은 말은 수달 받침 위에 팀 색 알약 **×2·×3** 으로 보여요. 판 안쪽 화살표가 도는 방향(오른쪽 아래 출발 → 위 → 왼쪽 → 아래 → 오른쪽)을 보여 줘요. 앱 아이콘은 핑크 네온 고리 안의 윷가락 4개예요 (`scripts/make_icons.py` 로 다시 만들 수 있음, Pillow·numpy 필요).

## 5. 게임 규칙

방장이 대기실에서 팀 수(2~4팀)와 팀당 말 개수(2~4개, 기본 4개)를 고르고 팀을 나눠요 (⇄ 팀 바꾸기, 🔀 팀 섞기, ▲▼ 팀 안에서 던지는 순서). 팀이 번갈아 가며 던지되 같은 팀 안에서는 던지는 사람이 차례로 돌아가요.

윷은 버튼을 누르거나 폰을 흔들어서 던져요 (📳 흔들어서 던지기 켜기, 아이폰은 처음에 동작 권한을 물어봐요). 흔들기는 세게 여러 번 흔들 때만 던져지고(0.8초 안에 강한 움직임 4번 이상), 가만히 두거나 탁자에 내려놓는 충격, 차례가 된 직후 1초는 무시해요. **낙은 없고** 도·개·걸·빽도는 **20%씩**, 윷·모는 **10%씩**이에요 (10/22).

던지는 순간 모든 폰에 **3D 윷 던지기**가 떠요: 윷가락 4개가 손에서 던진 것처럼 날아올라 구르고, 떨어져 통통 튀다가 결과 면으로 멈춰요 (바닥 판 없이 윷가락과 그림자만) (`src/three/yutThrow.js`, Three.js). 결과(배·등)는 던진 폰이 정한 값 그대로라 모든 폰이 같고, 움직임도 던지기 id 로 정해서 모든 폰에서 똑같이 보여요. 멈춘 윷가락끼리는 겹치지 않게 자리를 잡아요. Three.js 는 게임 화면에 들어올 때 따로 불러와서(홈 화면은 가벼움) 첫 던지기부터 바로 나오고, WebGL 이 안 되는 기기에서는 예전 윷가락 애니메이션이 나와요.

윷이나 모가 나오면 한 번 더 던지고, 모은 결과를 원하는 순서로 써요. 쓸 윷을 고르면 움직일 수 있는 말과 도착 칸이 빛나고, 아래 목록이나 판 위의 말·칸을 눌러 옮겨요. 빽도는 판 위의 말을 한 칸 뒤로 보내고, 판에 말이 없으면 무효예요. 윷가락 중 하나(빽도 윷)는 배에 XXX 대신 **'-'** 표시가 있어요.

말은 오른쪽 아래 **출발·골인** 칸에서 출발해 오른쪽 변을 따라 위로 올라가요. 오른쪽 위·왼쪽 위 **모서리**와 **가운데**에 멈춘 말은 다음 이동 때 **대각선(지름길)과 직진 중에서 골라요** (조작 바에 두 길이 다 뜨고, 판에서도 두 도착 칸이 빛나요). 지나가기만 하면 그대로 직진해요. 왼쪽 아래 모서리는 대각선이 끝나는 곳이라 고를 길이 없어요. **골인은 출발·골인 칸을 지나가야 해요** — 딱 멈추면 그 칸에 서 있다가(조작 바에 "출발·골인 칸에 멈춤"), 다음에 그 말을 한 칸이라도 움직이면 골인이에요. 빽도로 들어와도 같아서, 새 말이 도로 1번에 갔다가 빽도로 출발·골인 칸에 들어가면 대박이에요 (거기 서 있는 말도 상대가 와서 멈추면 잡혀요). 골인까지 바깥 한 바퀴는 37걸음, 가장 짧은 길(오른쪽 위 모서리 → 대각선 → 가운데 → 골인 쪽)은 20걸음이에요.

같은 팀 말이 있는 칸에 서면 업혀서 같이 움직이고, 다른 팀 말이 있는 칸에 서면 잡아요. 잡힌 팀은 전원이 잡힌 말 수만큼 마시고, 잡은 사람은 **그 칸 벌칙·게임도 그대로 한 다음** 한 번 더 던져요 (10/16 — 모서리 놉카드 +1·방패 +1·소주 +1도 받고, 4칸 뒤로·자석·운명의 카드도 그대로). 말을 먼저 다 들여보낸 팀이 이기고, **진 팀은 들어오지 못한 말 수만큼** 마셔요 (팀원 모두 그 잔 수씩 — 승리 화면과 오늘의 결과에 팀마다 "말 2개 못 들어옴 → 2잔씩"처럼 나와요).

**🛡️ 방패 (44·46·51번)**: 도착한 팀 방패 +1 (팀 단위, 여러 개 모을 수 있음, 점수판·팀 목록에 🛡️ 수). 우리 말이 잡히려고 하면 잡히기 전에 모든 폰에 "방패를 쓸까요?"가 뜨고, **잡힐 팀 사람 누구나** 고를 수 있어요. **쓰면** 안 잡히고 방패가 1개 줄어요 — 두 팀 말이 한 칸에 같이 서 있게 되고(판에 두 말이 칸 양쪽 위에), 잡으려던 사람은 한 번 더 없이 그 칸 미션을 해요. **안 쓰면** 원래대로 잡혀요. 시간 제한 없이 고를 때까지 기다려요 (잡힐 팀이 모두 연결이 끊겼으면 방장·던진 사람이 대신 골라요). 4칸 뒤로·자석·운명의 카드로 잡을 때도 똑같아요. 이동 선택지에 "🎯 파랑 잡기! (🛡️ 방패 있음)"처럼 미리 보여요.

**팀을 부를 때는 닉네임도 같이** 나와요 — 예: **빨강팀(상혁, 윤정)** (안내·버튼·로그·결과 화면 전부). 끝날 때도 진 팀을 바로 불러요 — 예: **"파랑팀(관희, 민수) 말 2개 못 들어옴 → 2잔씩 마셔!"**.

**연대책임**: 누군가 마셔야 하면 그 사람 **팀 전원이 같이** 마셔요 (AI 지목·돌발 미션·도박 등 전부, 🍺 잔 수도 팀원 모두 +1). "다 같이 마셔!"·"랜덤 n행시"처럼 전원 칸은 모두가 마시고, **"상대 1명 골라 같이 짠♥"은 고른 두 사람만** 마셔요.

**놉카드는 팀 단위**예요. 모서리(9·18·27번) **놉카드 +1** 칸에 도착하면 그 팀 카드가 +1 되고, 팀원 누구나 팀 카드를 1장씩 쓸 수 있어요. 놉카드는 **말로 쓰는 것**이라 칸에서 자동으로 '거부' 버튼이 뜨지 않아요 — 무엇을 거부하는지 말하고 팀 목록의 우리 팀 🎫 배지 → **1장 사용**을 누르면, **모든 폰에 '놉카드 사용' 팝업**(빨강팀(상혁, 윤정) 놉카드 1장 사용! · 남은 장수)이 뜨고 각자 **확인했어요**로 닫아요. 점수판에도 팀별 🎫 수가 보여요. "놉카드 내놔!"는 다른 팀 카드 1장을 우리 팀으로, "놉카드 도박"은 팀 카드를 걸어요.

**옵션 칸은 상대 팀에 걸려요.** 예를 들어 빨강팀이 영어금지 칸에 서면 **파랑팀에 영어금지 5분**이 걸리고, 모든 폰 위에 "파랑팀에 걸림" 타이머가 떠요 (3~4팀이면 우리 팀 빼고 모든 팀). 옵션은 모두 5분이고 **아니·근데·진짜 금지만 3분**이에요. 이미 걸려 있으면 시간이 더해지고, 옵션 해제 칸은 **우리 팀에 걸린 옵션만** 풀어요.

**소주 보관소 (가운데 40번, 고정 칸)**: "소주 +1 적립" 칸(2·12·19·32번)에 서면 보관소에 한 잔씩 모이고, 판의 40번 칸에 🍶 모인 잔 수가 떠요. 보관소에 도착한 팀이 모인 술을 **의리주**로 다 마시고(한 글라스에 모아 돌아가며), **도착한 사람이 마지막 순서**예요. 마시면 보관소는 비워져요.

말이 도착한 칸의 미션은 던진 사람이 진행해요. 칸 내용은 방장이 대기실에서 칸을 눌러 고칠 수 있고, 고친 칸은 원래 기능 대신 "수행 완료"만 있는 일반 칸이 돼요 (편집 창의 "원래대로"로 복구).

**팀 대결 미니게임** (모두 자기 폰으로 동시에 참여, 진 팀 전원이 마시고, **동점이면 룰렛**으로 마실 팀을 정함 · **시작은 그 칸에 걸린 사람만** 누를 수 있고(방장도 못 누름), 걸린 사람이 연결 끊겼을 때만 방장이 대신 시작):

- **🚇 지하철 게임 (5번)**: 훈민정음 게임처럼 3, 2, 1 뒤에 서울 지하철 노선 **15개**(1~9호선 + 수인분당선·신분당선·경의중앙선·경춘선·공항철도·경강선, 10/22 서해선·우이신설선·신림선·김포골드라인은 뺌) 중 하나가 노선 색으로 떠요 (바로 전에 나온 노선은 안 나옴, `src/game/subway.js`). 역 이름은 오프라인으로 돌아가며 말하고, 막히거나 틀리거나 나온 역을 또 말하면 마셔요. 던진 사람이 수행 완료. 게임 선택권에서도 골라요.
- **🧲 자석 (42·50번)**: 도착한 말(업힌 말도)에서 **앞뒤 2칸 안에 상대 말**이 있으면 우리 말이 **그쪽으로 끌려가서 잡아요** (잡은 팀은 한 번 더, 잡힌 팀은 마심). 여러 곳이면 던진 사람이 고르고(가까운 순), 상대 팀에 방패가 있으면 쓸지 물어봐요 — 쓰면 안 잡히고 끌려간 칸의 미션을 해요. 2칸 안에 없으면 **🎴 운명의 카드**: 카드를 뒤집어 ⏩ 3칸 앞으로 · ⏪ 2칸 뒤로(가서 상대 말이 있으면 잡고 그 칸 미션도, 골인하면 골인) · 🎫 놉카드 +1 · 🍻 다 같이 마셔! 중 하나 (같은 확률).
- **⏪ 4칸 뒤로**: 도착한 말이 (업힌 말도 같이) 4칸 뒤로 가요. 35번에서는 31번 이구동성 게임에 도착해서 그 칸 미션을 하고, 상대 말이 있으면 잡아요. 4칸 뒤로는 **놉카드로 거부할 수 없어요** (놉카드는 말로 쓰는 것 — 이동에는 못 씀).

주루마블과 같은 기능도 다 들어 있어요. 돌발 미션(던질 때 5% 확률, 직전 미션 뒤 5번 이상 던진 다음부터, **대기실에서 방장이 🎯 돌발 미션 On/Off**, 수행 시간이 끝나면 방장 폰이 퀴즈로 넘기고 방장 폰이 잠겨 있으면 수행자 폰이 3초 뒤에 대신), 🍺 오늘의 술고래 순위(벌칙으로 마실 때 자동 집계), ≡ 게임 로그, 비밀번호 방, 홈 화면 방 목록, 게임 중 합류(인원이 적은 팀으로), 방장 위임, 방 자동 정리(참가자가 모두 끊긴 채 30분 활동 없는 방, 대기실 1시간 — 게임이 끝나고 대기실로 돌아온 때부터 셈, 24시간. 지금 들어가 있는 방은 그 폰이 지우지 않음)가 그대로 동작해요. 접속 표시는 폰 화면을 껐다 켜서 다시 연결되면 다시 켜져요. 대기실로 돌아가면 이긴 팀과 잔 수 랭킹이 담긴 오늘의 결과 카드가 떠요.

## 7. 구조

`src/game/yut.js` 10×10 윷판 노드·좌표·번호·칸 내용, 윷 던지기, 말 이동(갈림길 대각선/직진·빽도·골인) 규칙. `src/room.js` 방·팀·차례·던지기·옮기기·잡기·업기·승리, 팀 놉카드·방패(`shieldDecide`)·자석(`magnetTargets`)·운명의 카드(`FATE_CARDS`)·칸 효과 이동(`forcedMoveUpdates`: 4칸 뒤로·자석·운명의 카드 공통)·연대책임·옵션·소주 보관소, 미니게임과 팀 대결 게임 진행(DB 읽기·쓰기, 결과 계산). `src/components/YutBoard.jsx` 윷판, `src/components/TeamGames.jsx` 팀 대결 게임 화면, `src/components/YutSticks.jsx` 윷가락·던지기, `src/three/` 3D (윷 던지기, 수달 말 그림의 원본 모델), `src/App.jsx` 화면, `src/styles.css`. `src/db.js` Firebase/데모 저장소, `src/game/` 아래 폭탄 주제·돌발 미션·n행시 데이터, 완벽한 원 채점(`circle.js`), 편의점 가격(`prices.js`), 지도 찍기 장소(`places.js`)·지도(`mapdata.js`), 세계 지도 찍기 장소(`worldplaces.js`)·도법(`worldgeo.js`)·지도(`worldmap.js`), 지하철 호선(`subway.js`), 단어 노래 단어(`songwords.js`), 노래·영화 맞히기 제목·영화 이모지·힌트(`titles.js`)·정답 비교·초성·차트 곡 정리·문제 고르기(`mediaquiz.js`)·걸린 사람 폰 소리(`mqaudio.js`)와 자동 이모지 규칙. `api/media.js` 는 Vercel 서버 함수(노래 맞히기 미리듣기·지금 차트 찾기), `src/components/MediaCheck.jsx` 는 확인 화면(`?mediacheck=1`). 효과음은 `src/sound.js` 에서 `SOUND_ENABLED = true` 로 켤 수 있어요 (기본 꺼짐).

## 8. 수달 말

판 위 말은 **3D 수달 모델**(`src/three/otter.js`)을 팀 색 목띠·받침으로 비스듬히 위에서 찍은 그림이에요 (`src/assets/otters/otter-0~3.webp`, 99×120, 하나에 약 6KB — 판은 평면 그대로). 칸 오른쪽 위 모서리에 서 있고 몸은 칸 사이 틈 쪽이라 칸 글자를 덜 가려요. 업은 말은 받침 위에 팀 색 알약 ×2·×3, 움직일 수 있는 말은 통통 튀면서 팀 색으로 빛나요. 한 칸에 여러 팀이 있으면(방패) 두 번째 팀부터 왼쪽 위·오른쪽 아래·왼쪽 아래.

수달은 사진을 세운 게 아니라 실제 입체 모델이에요 (`src/three/otter.js`): 몸통·머리·팔·꼬리는 법선 방향으로 여러 겹 부풀린 **털 껍질(shell) 셰이더**로 보송한 갈색 털을 그리고, 크림색 얼굴(볼·주둥이·턱)·눈썹 자리·가슴과 배는 꼭짓점 색으로 경계를 부드럽게 칠해요. 반짝이는 까만 눈, 코, 웃으며 벌린 입과 혀, 귀, 수염, 손가락이 있는 앞발, 발톱이 있는 뒷발, 두툼한 꼬리가 있어요. 팀마다 **목띠와 원형 받침 색만** 달라요 (1팀 빨강 · 2팀 파랑 · 3팀 초록 · 4팀 노랑, 참고 이미지 색). 모양·재질은 모든 말이 같이 써서 여러 마리를 놓아도 가벼워요.

그림을 다시 만들려면 `node tools/make_otters.mjs [크기=256] [옆으로 돌린 각도=28] [내려다보는 각도=16]` — vite 개발 서버를 잠깐 띄워 `tools/otter-render/` 를 열고 WebGL 로 팀 4개를 찍은 뒤 같은 테두리로 잘라 webp 로 저장해요 (`tools/` 는 테스트 도구, 저장소에는 안 올림). 예전 3D 판 예시 페이지(`otter.html`·`src/three/board3d.js`)는 10/16 지웠어요 (git 기록에 남아 있음).
