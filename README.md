# 주루윷놀이 (Juruyut)

팀을 나눠 각자 폰으로 윷을 던지는 술자리 윷놀이 웹앱이에요. 같은 방에 들어온 모든 폰이 Firebase Realtime Database 로 실시간 동기화되고, 윷판의 모든 칸에 미션·미니게임·놉카드가 들어 있어요. 주루마블과 같은 Firebase 프로젝트를 쓰지만 데이터 위치(`yutRooms`)가 달라서 서로 섞이지 않아요.

## 1. Firebase 준비

주루마블에서 만든 `juru-marvel` 프로젝트를 그대로 써요. 콘솔 → Realtime Database → 규칙 탭에 아래 내용을 붙여넣고 **게시**하세요 (`database.rules.json` 과 같음). 주루마블(`rooms`)과 주루윷놀이(`yutRooms`)를 둘 다 열어 두는 규칙이고, 테스트 모드와 달리 만료가 없어요.

```json
{
  "rules": {
    "rooms": { ".read": true, ".write": true },
    "yutRooms": { ".read": true, ".write": true }
  }
}
```

다른 Firebase 프로젝트를 쓰려면 `src/firebase.js` 의 설정값을 바꾸고, 미국 리전이 아니면 `.env` 에 `VITE_FIREBASE_DB_URL` 을 넣으세요 (`.env.example` 참고).

## 2. 배포 (GitHub → Vercel)

이 저장소를 Vercel 에서 Import 하면 끝이에요. Framework 는 Vite 로 자동 인식되고, Build Command `npm run build`, Output `dist` 가 기본값이에요. main 브랜치에 push 할 때마다 자동으로 다시 배포돼요.

## 3. 실행 (내 컴퓨터)

```bash
npm install
npm run dev
```

`http://localhost:5173/?demo=1` 로 열면 서버 없이 한 기기에서 가짜 참가자 3명과 함께 미리 볼 수 있어요. `http://localhost:5173/otter.html` 은 3D 수달 말 예시예요 (아래 8번).

## 4. 화면

주루마블과 다른 **포장마차 네온** 테마예요. 기본은 밤(남색 밤하늘 + 네온 주황·소주병 초록·핑크), 오른쪽 위 해 버튼을 누르면 낮(주황 천막·크림)으로 바뀌어요. 제목·버튼 글씨는 간판 느낌의 Black Han Sans(`@fontsource/black-han-sans`, 앱에 같이 묶여서 배포), 본문은 Pretendard 예요.

게임 화면은 위에 팀 점수판(팀별 말 ○집 ●판 ◎골인과 골인 수), 가운데 윷판, 그 아래 팀원·놉카드 목록이 있고, 화면 아래에 고정된 조작 바에서 지금 차례·윷 결과·말 고르기·던지기를 해요. 윷가락이 돌아가는 동안에는 결과 칩과 윷가락 모양을 숨겨서 미리 보이지 않아요.

윷판은 **10×10** (한 변에 10칸, 바깥 36칸 + 대각선 16칸 + 가운데 = 53칸)이에요. 판은 항상 한 화면에 전체가 보이고, 칸마다 번호·이모지·벌칙 글자가 같이 보여요 (크게/작게 보기 전환 없음). 모서리(9·18·27번)와 가운데(40번)는 **보라 네온 테두리**예요 (주황 깜빡임은 '갈 수 있는 칸' 전용이라 헷갈리지 않게). 칸을 거의 맞닿게 키우고 판을 화면 가장자리까지 넓혔고, 글자는 **모든 칸이 같은 크기**(판 너비의 1.9%, `YutBoard.jsx` 의 `CELL_FS`)이고, 그 크기로 안 들어가는 줄만 띄어쓰기에서 나누며, 나눠도 안 들어가는 긴 단어만 그 칸에서 조금 작아져요 (`fitCellText`). 글자 크기는 판 너비 기준(CSS 컨테이너 단위 cqw)이라 어느 화면에서든 같은 모양이에요. 칸 글자는 한 줄 4자 안팎, 세 줄 이내면 다른 칸과 같은 크기로 보여요. 말은 칸 오른쪽 위 모서리의 작은 점이고 그 칸 테두리가 팀 색으로 빛나요. 업은 말은 팀 색 알약에 **×2·×3** 으로 크게 보여요. 판 안쪽 화살표가 도는 방향(오른쪽 아래 출발 → 위 → 왼쪽 → 아래 → 오른쪽)을 보여 줘요. 앱 아이콘은 핑크 네온 고리 안의 윷가락 4개예요 (`scripts/make_icons.py` 로 다시 만들 수 있음, Pillow·numpy 필요).

## 5. 게임 규칙

방장이 대기실에서 팀 수(2~4팀)와 팀당 말 개수(2~4개, 기본 4개)를 고르고 팀을 나눠요 (⇄ 팀 바꾸기, 🔀 팀 섞기, ▲▼ 팀 안에서 던지는 순서). 팀이 번갈아 가며 던지되 같은 팀 안에서는 던지는 사람이 차례로 돌아가요.

윷은 버튼을 누르거나 폰을 흔들어서 던져요 (📳 흔들어서 던지기 켜기, 아이폰은 처음에 동작 권한을 물어봐요). 흔들기는 세게 여러 번 흔들 때만 던져지고(0.8초 안에 강한 움직임 4번 이상), 가만히 두거나 탁자에 내려놓는 충격, 차례가 된 직후 1초는 무시해요. **낙은 없고** 도·개·걸·윷·모·빽도가 모두 같은 확률(각 1/6)이에요.

던지는 순간 모든 폰에 **3D 윷 던지기**가 떠요: 윷가락 4개가 손에서 던진 것처럼 날아올라 구르고, 떨어져 통통 튀다가 결과 면으로 멈춰요 (바닥 판 없이 윷가락과 그림자만) (`src/three/yutThrow.js`, Three.js). 결과(배·등)는 던진 폰이 정한 값 그대로라 모든 폰이 같고, 움직임도 던지기 id 로 정해서 모든 폰에서 똑같이 보여요. 멈춘 윷가락끼리는 겹치지 않게 자리를 잡아요. Three.js 는 게임 화면에 들어올 때 따로 불러와서(홈 화면은 가벼움) 첫 던지기부터 바로 나오고, WebGL 이 안 되는 기기에서는 예전 윷가락 애니메이션이 나와요.

윷이나 모가 나오면 한 번 더 던지고, 모은 결과를 원하는 순서로 써요. 쓸 윷을 고르면 움직일 수 있는 말과 도착 칸이 빛나고, 아래 목록이나 판 위의 말·칸을 눌러 옮겨요. 빽도는 판 위의 말을 한 칸 뒤로 보내고, 판에 말이 없으면 무효예요. 윷가락 중 하나(빽도 윷)는 배에 XXX 대신 **'-'** 표시가 있어요.

말은 오른쪽 아래 **출발·골인** 칸에서 출발해 오른쪽 변을 따라 위로 올라가요. 오른쪽 위·왼쪽 위 **모서리**와 **가운데**에 멈춘 말은 다음 이동 때 **대각선(지름길)과 직진 중에서 골라요** (조작 바에 두 길이 다 뜨고, 판에서도 두 도착 칸이 빛나요). 지나가기만 하면 그대로 직진해요. 왼쪽 아래 모서리는 대각선이 끝나는 곳이라 고를 길이 없어요. 출발·골인 칸에 도착하거나 지나가면 골인이에요. 바깥 한 바퀴는 36칸, 가장 짧은 길(오른쪽 위 모서리 → 대각선 → 가운데 → 골인 쪽)은 19칸이에요.

같은 팀 말이 있는 칸에 서면 업혀서 같이 움직이고, 다른 팀 말이 있는 칸에 서면 잡아요. 잡힌 팀은 전원이 잡힌 말 수만큼 마시고, 잡은 팀은 한 번 더 던져요. 말을 먼저 다 들여보낸 팀이 이기고, 나머지 팀이 모두 마셔요.

**🛡️ 방패 (42·46번)**: 도착한 팀 방패 +1 (팀 단위, 여러 개 모을 수 있음, 점수판·팀 목록에 🛡️ 수). 우리 말이 잡히려고 하면 잡히기 전에 모든 폰에 "방패를 쓸까요?"가 뜨고, **잡힐 팀 사람 누구나** 고를 수 있어요. **쓰면** 안 잡히고 방패가 1개 줄어요 — 두 팀 말이 한 칸에 같이 서 있게 되고(판에 두 말이 칸 양쪽 위에), 잡으려던 사람은 한 번 더 없이 그 칸 미션을 해요. **안 쓰면** 원래대로 잡혀요. 시간 제한 없이 고를 때까지 기다려요 (잡힐 팀이 모두 연결이 끊겼으면 방장·던진 사람이 대신 골라요). 4칸 뒤로 가서 잡을 때도 똑같아요. 이동 선택지에 "🎯 파랑 잡기! (🛡️ 방패 있음)"처럼 미리 보여요.

**연대책임**: 누군가 마셔야 하면 그 사람 **팀 전원이 같이** 마셔요 (AI 지목·돌발 미션·도박 등 전부, 🍺 잔 수도 팀원 모두 +1). "다 같이 마셔!"·"랜덤 n행시"처럼 전원 칸은 모두가 마시고, **"상대 1명 골라 같이 짠♥"은 고른 두 사람만** 마셔요.

**놉카드는 팀 단위**예요. 모서리(9·18·27번) **놉카드 +1** 칸에 도착하면 그 팀 카드가 +1 되고, 팀원 누구나 팀 카드를 1장씩 쓸 수 있어요 (팀 목록의 우리 팀 🎫 배지 → 사용, 모두에게 알림). 점수판에도 팀별 🎫 수가 보여요. "놉카드 내놔!"는 다른 팀 카드 1장을 우리 팀으로, "놉카드 도박"은 팀 카드를 걸어요.

**옵션 칸은 상대 팀에 걸려요.** 예를 들어 빨강팀이 영어금지 칸에 서면 **파랑팀에 영어금지 5분**이 걸리고, 모든 폰 위에 "파랑팀에 걸림" 타이머가 떠요 (3~4팀이면 우리 팀 빼고 모든 팀). 옵션은 모두 5분이고 **아니·근데·진짜 금지만 3분**이에요. 이미 걸려 있으면 시간이 더해지고, 옵션 해제 칸은 **우리 팀에 걸린 옵션만** 풀어요.

**소주 보관소 (가운데 40번, 고정 칸)**: "소주 +1 적립" 칸(2·12·19·32번, 지금은 대각선 빈칸 43·44·50·51번도)에 서면 보관소에 한 잔씩 모이고, 판의 40번 칸에 🍶 모인 잔 수가 떠요. 보관소에 도착한 팀이 모인 술을 **의리주**로 다 마시고(한 글라스에 모아 돌아가며), **도착한 사람이 마지막 순서**예요. 마시면 보관소는 비워져요.

말이 도착한 칸의 미션은 던진 사람이 진행해요. 칸 내용은 방장이 대기실에서 칸을 눌러 고칠 수 있고, 고친 칸은 원래 기능 대신 "수행 완료"만 있는 일반 칸이 돼요 (편집 창의 "원래대로"로 복구).

**🎯 혼자 연습 게임** (홈 화면): 게임 선택권처럼 팀 게임 9개 중 하나를 골라 혼자 미리 해 볼 수 있어요. 서버 없이 그 폰 메모리에서만 돌아가고(`?practice=게임`), 가짜 참가자는 **연습봇1**(우리 팀)·**연습봇2·연습봇3**(상대 팀)이에요 (줄다리기는 가짜도 같이 연타, 반응속도는 한 번만 탭, 폭탄은 펑 뒤 몇 초 버텼는지). 시작 전 안내 화면에서 **← 다른 게임**으로 돌아가 다른 게임을 고를 수 있고, 끝나면 연습 화면에서 **↻ 다시 하기**나 다른 게임, **🏠 홈으로**.

## 8. 3D 수달 말 (Three.js)

`otter.html` (배포 주소 `/otter.html`, 홈 화면 링크는 없앰 — 주소로만)은 실행해 볼 수 있는 예시예요. 게임 판에는 쓰지 않아요 (평면 판 + 점 말). 게임과 같은 10×10 윷판(칸 번호·이모지·글자 그대로)을 3D 로 만들고, 게임의 말 상태 형식 그대로 두 팀 말을 배치해요 (빨강: 4번·37번에 업힌 말 2개·대기 1개 / 파랑: 17번·가운데·골인 1개·대기 1개). 빈 곳을 끌면 판이 돌아가고, 말을 누르고 좌우로 끌면 그 말만 회전해요. 위의 팀·크기를 고르고 **＋ 말 추가**를 누르면 그 팀·크기로 빈 칸에 새 말이 생겨요 (선택한 말에도 팀·크기가 바로 적용). **🏆 쇼룸**은 네 팀 수달을 나란히 보여 줘요.

수달은 사진을 세운 게 아니라 실제 입체 모델이에요 (`src/three/otter.js`): 몸통·머리·팔·꼬리는 법선 방향으로 여러 겹 부풀린 **털 껍질(shell) 셰이더**로 보송한 갈색 털을 그리고, 크림색 얼굴(볼·주둥이·턱)·눈썹 자리·가슴과 배는 꼭짓점 색으로 경계를 부드럽게 칠해요. 반짝이는 까만 눈, 코, 웃으며 벌린 입과 혀, 귀, 수염, 손가락이 있는 앞발, 발톱이 있는 뒷발, 두툼한 꼬리가 있어요. 팀마다 **목띠와 원형 받침 색만** 달라요 (1팀 빨강 · 2팀 파랑 · 3팀 초록 · 4팀 노랑, 참고 이미지 색). 모양·재질은 모든 말이 같이 써서 여러 마리를 놓아도 가벼워요.

```js
import { createOtterPiece } from './src/three/otter'
import { createYutBoard3D, syncPieces } from './src/three/board3d'

const otter = createOtterPiece({ team: 1, size: 0.8 }) // team 0~3 = 1팀 빨강~4팀 노랑, fur: 'high' | 'low' | 'off'
scene.add(otter)
otter.rotation.y = Math.PI / 4       // 돌리기
otter.userData.setTeam(2)            // 팀(목띠·받침 색) 바꾸기
otter.userData.setSize(1.2)          // 크기 바꾸기

const board = createYutBoard3D({ cells: DEFAULT_YUT_CELLS })
scene.add(board.group)
syncPieces(board, roomPieces(room), { teamCount: 2, size: 0.62 }) // 게임 말 상태 그대로 배치
```

`node tools/yotter.mjs turn,showroom,board` 로 앞·옆·뒤·비스듬히, 네 팀, 윷판 스크린샷을 찍어 볼 수 있어요 (`tools/` 는 테스트 도구, 저장소에는 안 올림).
